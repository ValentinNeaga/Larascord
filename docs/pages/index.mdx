# Introduction
 
Welcome to Larascord documentation.

## What is Larascord?

Larascord is a package that allows you to authenticate users in your Laravel application using Discord's OAuth2 protocol.

It allows users to log in to your platform using their Discord account without the need to handle/store any of the user's sensitive credentials.

It also seamlessly integrates with Discord, providing a secure and user-friendly way to authenticate users in your application.

## Existing applications

Larascord can be installed in an application that already has a `users` table, authentication and views.

* The Discord profile is stored in the `larascord_accounts` table and linked to your user model through a `user_id` foreign key. The `users` table is not modified.
* No views, assets or starter kits are published.
* All routes are registered under the configured prefix and named with a `larascord.` prefix.
* The package adds one configuration file, `config/larascord.php`, and two tables, `larascord_accounts` and `larascord_access_tokens`.
