# Introduction
 
Welcome to Larascord documentation.

## What is Larascord?

Larascord is a package that allows you to authenticate users in your Laravel application using Discord's OAuth2 protocol.

It allows users to log in to your platform using their Discord account without the need to handle/store any of the user's sensitive credentials.

It also seamlessly integrates with Discord, providing a secure and user-friendly way to authenticate users in your application.

## Does it work with my existing project?

Yes. Larascord keeps to itself:

* It stores the Discord profile in its own tables and links it to your users through a foreign key, so your `users` table stays yours.
* It does not publish views and does not install a starter kit, so your UI is untouched.
* Every route it registers lives under its own prefix and is named `larascord.*`, so nothing of yours is overwritten.
* Removing the package and dropping its two tables leaves your application working.
