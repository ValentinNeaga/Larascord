## The Login Attempt Has Expired
This error occurs when the `state` parameter Discord sends back does not match the one Larascord put in the session.

It happens when:
* The user opened the Discord authorization page, left it open for longer than the session lifetime and then authorized the application.
* The user reached `/larascord/callback` directly instead of going through `/larascord/redirect`.
* You built the authorization URL yourself without putting the state in the session.

If you build the URL yourself, generate the state through the facade and store it before redirecting:

```php
use Jakyeru\Larascord\Facades\Larascord;

$state = Larascord::generateState();

session()->put(Larascord::STATE_KEY, $state);

return redirect()->away(Larascord::authorizationUrl($state));
```

If your application cannot keep the state in the session, set `verify_state` to `false` in `config/larascord.php`.
