## What is the DiscordAccount model?

`Jakyeru\Larascord\Models\DiscordAccount` is the record Larascord keeps for every Discord profile that has logged in to your application. It lives in the `larascord_accounts` table and holds a `user_id` pointing at one of your users.

This is where the Discord profile lives, which is why your `users` table does not have to know that Discord exists.

## Getting an account

```php
use Jakyeru\Larascord\Models\DiscordAccount;

$account = DiscordAccount::forUser(auth()->user());

$account = DiscordAccount::forDiscordId('81384788765712384');

$account = auth()->user()->discordAccount;
```

<Callout type="info">
    The last one needs the `InteractsWithDiscord` trait on your `User` model. The first two work without it.
</Callout>

## Attributes

| Attribute | Type | Description |
|:---|:---|:---|
| `user_id` | mixed | The primary key of the user the account is linked to. |
| `discord_id` | string | The user's Discord ID. |
| `username` | string | The user's unique Discord username. |
| `global_name` | string | The user's global display name. |
| `display_name` | string | The global display name, falling back to the username. |
| `tag` | string | The user's tag, for example `jakye` or `jakye#0001`. |
| `discriminator` | string | The user's discriminator. |
| `email` | string | The e-mail address of the Discord account. |
| `avatar` | string | The avatar hash. |
| `verified` | bool | Whether the e-mail address is verified. |
| `banner` | string | The banner hash. |
| `banner_color` | string | The banner color. |
| `accent_color` | string | The accent color. |
| `locale` | string | The user's locale. |
| `mfa_enabled` | bool | Whether the user has multifactor authentication enabled. |
| `premium_type` | int | The user's Nitro subscription type. |
| `public_flags` | int | The user's public flags. |

## Relationships

```php
$account->user;

$account->accessToken;
```

## Methods

The account exposes the same Discord API methods as the `InteractsWithDiscord` trait, which are documented [here](/interacts_with_discord).

```php
$account->getAvatar(['size' => 64]);
$account->getAccessToken();
$account->refreshAccessToken();
$account->getGuilds();
$account->getGuildMember('81384788765712384');
$account->joinGuild('81384788765712384');
$account->getConnections();
```

### revoke
<Callout type="warning">
    This method revokes the OAuth2 access token with Discord and deletes the account. The user itself is left alone.
</Callout>

/**
