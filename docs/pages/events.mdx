Larascord dispatches its own events. There is nothing to publish and nothing to register, they are dispatched from the package and you listen to them like any other Laravel event.

| Event | Dispatched when | Properties |
| --- | --- | --- |
| `DiscordAccountCreated` | A Discord account is stored for the first time. | `$account` |
| `DiscordAccountUpdated` | A known Discord account comes back and its profile is refreshed. | `$account` |
| `DiscordAccountLinked` | A Discord account is attached to one of your users. | `$account`, `$user` |
| `DiscordAccountUnlinked` | A Discord account is removed. | `$account` |
| `UserAuthenticated` | A user is logged in through Discord. | `$account`, `$user` |

<Callout type="info">
    Every event lives in the `Jakyeru\Larascord\Events` namespace and `$account` is always a `Jakyeru\Larascord\Models\DiscordAccount`.
</Callout>

## Listening
<Steps>
    ### Create a listener
    ```bash
    php artisan make:listener WelcomeNewUser
    ```

    ### Type hint the event
    Laravel discovers the listener from the type hint, so there is nothing else to register.

    ```php filename="app/Listeners/WelcomeNewUser.php" showLineNumbers
    <?php

    namespace App\Listeners;

    use Illuminate\Support\Facades\Log;
    use Jakyeru\Larascord\Events\DiscordAccountCreated;

    class WelcomeNewUser
    {
        public function handle(DiscordAccountCreated $event): void
        {
            Log::info('Welcome ' . $event->account->tag);
        }
    }
    ```
</Steps>

## Example: adding the user to a guild after they log in

```php filename="app/Listeners/AddUserToGuild.php" showLineNumbers
<?php

namespace App\Listeners;

use Jakyeru\Larascord\Events\UserAuthenticated;

class AddUserToGuild
{
    public function handle(UserAuthenticated $event): void
    {
        $event->account->joinGuild('81384788765712384');
    }
}
```

## Example: refusing a banned user

```php filename="app/Listeners/BlockBannedUsers.php" showLineNumbers
<?php

namespace App\Listeners;

use Illuminate\Support\Facades\Auth;
use Jakyeru\Larascord\Events\UserAuthenticated;

class BlockBannedUsers
{
    public function handle(UserAuthenticated $event): void
    {
        if ($event->user->is_banned) {
            Auth::logout();
        }
    }
}
```
